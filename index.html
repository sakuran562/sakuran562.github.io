ピアノとのつなぎ方（iPad）

  1. App Store から無料アプリ「Web MIDI Browser」を入れる。
  2. ロールアップピアノの Bluetooth をオンにして、Web MIDI Browser のメニューから Bluetooth MIDI でピアノに接続する。
  3. Web MIDI Browser でこのページを開く。上の丸が緑になって、ピアノの名前が出たら準備完了。
  4. 青く光った鍵盤を右手で、オレンジ色の鍵盤を左手で弾く。正しい音を弾くまで次には進まないよ。

楽譜の見方：1〜4小節は、左手もト音記号で書かれています。指番号は楽譜に書いてあるものだけを表示しています。
